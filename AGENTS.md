# Spiking depth estimation

- This is a standalone code repository. Keep research reports, papers, historical run records, datasets and checkpoints outside Git. `Spiking Transformer.md` is the imported master-note snapshot.
- Keep model calculations unchanged during repository maintenance. Explain and test intentional architecture or training changes separately.

- Supply data and output paths via arguments/environment. Do not hard-code personal paths or cluster credentials.
- Preserve upstream attribution and licenses. `vendor/s2m2` has its own noncommercial license; the main MIT license does not override it.
- Record configuration, source revision and dataset split for new experiments. Do not claim historical result equivalence for the new portable runner.
- Do not commit or push unless requested. Keep the source Research repository intact.
